## Projetos em destaque

### Skill Map

Sistema web para **gestão de habilidades operacionais**, alocação de operadores, controle de frequência e análise de desempenho da equipe.

Principais recursos:

- cadastro e gestão de operadores;
- matriz de habilidades por posto, linha e modelo;
- dashboards analíticos;
- controle de frequência;
- gestão de acesso por permissões;
- auditoria de ações;
- indicadores como Skill Ratio, multifuncionalidade, matriz talento vs confiabilidade e radar de equipe.

Repositório: [github.com/carlosdaniel003/Skill-Map](https://github.com/carlosdaniel003/Skill-Map)

---

### SIGMA-Q

Sistema web para **análise de indicadores de qualidade**, PPM, defeitos, causas, modelos, responsabilidade e diagnóstico técnico com apoio de IA.

Principais recursos:

- dashboard técnico de qualidade;
- análise de PPM;
- filtros por período, categoria, modelo, turno e responsabilidade;
- diagnóstico inteligente baseado em histórico e FMEA;
- ranking de defeitos críticos;
- identificação de tendências e agrupamentos de falhas.

Repositório: [github.com/carlosdaniel003/sigma-q-v5](https://github.com/carlosdaniel003/sigma-q-v5)

---

### VisionX Neural

Sistema em Python para **inspeção visual industrial**, com visão computacional, análise de anomalias e painel técnico de depuração.

Principais recursos:

- comparação entre gabarito e imagem de teste;
- análise visual com SSIM e diferenças estruturais;
- depuração com mapas visuais;
- apoio à classificação de defeitos;
- estrutura preparada para evolução com dataset local e aprendizado assistido.

Repositório: [github.com/carlosdaniel003/visionx-neural](https://github.com/carlosdaniel003/visionx-neural)

---

### LUMUS-PCI

Sistema desktop em Python para **análise visual de LEDs em placas PCI**, com inspeção assistida e identificação de LEDs acesos e apagados.

Principais recursos:

- carregamento de imagens de placas;
- seleção de LEDs por região de interesse;
- análise visual do estado dos LEDs;
- mapa de intensidade;
- ROI ampliado;
- debug técnico;
- painel operacional para apoio à validação.

Repositório: [github.com/carlosdaniel003/LUMUS-PCI](https://github.com/carlosdaniel003/LUMUS-PCI)

---

### Central de Aprovações CA

Sistema web em PHP para **registro, armazenamento e consulta de aprovações técnicas**, com documentação fotográfica e base de consultas.

Principais recursos:

- cadastro de novas aprovações;
- anexos de ficha técnica e foto do defeito;
- consulta por modelo e sintoma;
- visualização de ficha oficial;
- organização de registros técnicos para apoio à produção e qualidade.

Repositório: [github.com/carlosdaniel003/Central-de-Aprovacoes-CA](https://github.com/carlosdaniel003/Central-de-Aprovacoes-CA)
